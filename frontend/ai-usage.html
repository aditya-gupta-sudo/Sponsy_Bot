How to read these limits

The tracker reports calls made through SponsyBot, not independent usage from other apps or API keys.

Tracked usage counts provider calls logged by the SponsyBot backend.

Configured limit must match the quota for your active provider account and model. Provider quotas can vary by plan and model.

Reset countdown is based on the reset window configured for that provider. Use the provider dashboard to verify the official quota state.
